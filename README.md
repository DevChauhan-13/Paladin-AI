# Paladin AI 🛡️

**AI-Based Cyber Threat Detection System**

Paladin AI provides real-time streaming threat detection, packet inspection, anomaly analysis, and forensic triage for unidirectional network links, data diodes, and secure enterprise defense perimeters.

---

## 🚀 Features

- **Real-Time Streaming Threat Detection:** Dynamic telemetry analysis and multi-vector attack detection.
- **Forensic Triage & Deep Packet Inspection:** Automated alert prioritization and threat scoring.
- **Data Diode & Unidirectional Link Integration:** Optimized for high-security air-gapped perimeters.
- **Interactive Security Dashboard:** High-tech visualizations, live network topology maps, and incident history.
- **SOM & Machine Learning Analytics:** Self-Organizing Maps (SOM) for unsupervised anomaly identification.

---

## 🛠️ Built With

- **HTML5 & Modern Vanilla CSS** (Tailored cyber/defense aesthetic with glassmorphism & neon indicators)
- **Modular JavaScript (ES6+)**
- **Chart.js / Canvas APIs** for telemetry dashboards

## 🔧 Getting Started

### Prerequisites

No complex build pipeline required. Any modern web browser (Chrome, Edge, Firefox, Safari) can serve the site locally.

### Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/DevChauhan-13/Paladin-AI.git
   cd Paladin-AI
   ```

2. **Serve locally:**
   Open `index.html` directly in your browser or run a lightweight local HTTP server:
   ```bash
   # Using Python
   python -m http.server 8000

   # Or using Node.js http-server
   npx http-server .
   ```
